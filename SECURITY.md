# Reporting a security or privacy issue

Contact the maintainers privately if you find a credential, a household record or a way for private data to enter a public release. Use **Security > Report a vulnerability** on GitHub when available. Give the affected revision, file path and a short description. Keep live credentials, addresses, floor plans and client files out of public issues and pull requests.

If a credential has been exposed, its owner should revoke or rotate it with the provider. Removing a file from the latest commit leaves earlier copies in Git history. The maintainers should also check pull requests, releases and workflow logs when assessing the exposure.
