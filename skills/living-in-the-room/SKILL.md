# Living in the Room

Start with one ordinary moment from the household brief. Who comes through which door, where do they sit, what do they want to reach or see, and what is the next person doing? Follow the action in both directions. Record the first awkward action, the position and the object responsible. A clear centre aisle can coexist with an unusable seat.

| Moment | Evidence to use |
| --- | --- |
| Enter and move through | Follow the [occupied route study](../freecad-renovation/references/route-studies.md) from each access point at the household's required width. Include thresholds, fixed projections and carried items. |
| Approach, turn, sit and rise | Trace each individual place from its usable front. Include chair pull-back, knees, arms and space to turn. Use the [living-design review](../renovation-pack/references/layout-review.md) for sightlines, conversation, reach and the footprint of other people using the room. |
| Someone else opens a door, passes or uses storage | Inspect the [full opening movement](../freecad-renovation/references/opening-clearances.md) with the seats occupied. Test each cupboard and appliance with the user at the handle and the fitting deployed. Compare the moving, parked and shut positions and the journey that remains possible in each relevant state. |
| Dress the room and walk it again | Reopen the final Blender scene. Run the [fully dressed walkthrough](../renovation-pack/references/handover-gates.md#fully-dressed-walkthrough) with pots, projecting foliage, lamps, low tables and other loose obstacles included. Reuse its stops, inventory, measurements and render hold. |
| Inspect the photograph as a person using the room | Compare the final pixels with the checked camera, intended mechanism and occupied plan. Look beside each leaf for a trapped seat, a blocked return route or a new accessory. Apply the [photo checks](../renovation-pack/references/photo-quality.md). Use a reverse camera or keyed plan if a decisive clearance is hidden. |

When open leaves flank armchairs, trace how each person reaches the seat, gets up and gets out while the other remains seated. On both sides of the opening, check what the door does during this sequence. If the design specifies sliders but the photograph shows swinging panels, hold the image and correct it from the reviewed camera. If both show the swing, return to layout review. Where changes are permitted, compare seat positions or a sliding arrangement with measured panel parking space, track, handle access and clear opening. Keep any consequential change of mechanism with the homeowner.

Record the evidence in the existing room and photo reviews. Report which activities worked, which failed and which need a measurement. Rerun affected journeys and review the corrected camera and final photograph before issue.
